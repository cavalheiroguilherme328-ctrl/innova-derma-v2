# INNOVA DERMA V2

Projeto front-end de demonstração fictícia para portfólio de uma clínica de estética premium.

## Visão geral
A V2 foi desenvolvida como uma landing page moderna para apresentar a marca INNOVA DERMA, com foco em:
- estética premium
- rejuvenescimento facial
- cuidados faciais e corporais
- avaliação estética personalizada
- conversão e agendamento em fluxo demonstrativo

O site foi construído para funcionar como apresentação de portfólio e não como clínica real. Todos os contatos e integrações demonstrativas devem ser substituídos antes da publicação oficial.

## Tecnologias utilizadas
- HTML5 semântico
- CSS3 com variáveis e responsividade
- JavaScript puro
- Fontes externas do Google Fonts
- Imagens externas do Unsplash

## Funcionalidades
- navegação principal com menu mobile
- hero com destaque visual e CTA
- seções de diferenciais, clínica, tratamentos, processo e FAQ
- formulário de agendamento em modo demonstrativo
- integração com WhatsApp em modo de demonstração
- estados de foco e acessibilidade básica
- SEO técnico com metadados e Open Graph

## Como executar localmente
Na pasta V2:

```bash
cd /home/guest/Projetos_T.I/INNOVA-DERMA/V2
python3 -m http.server 8000
```

Depois abra no navegador:

```text
http://localhost:8000/
```

## Limitações da integração demonstrativa
- o WhatsApp permanece em modo demonstrativo
- não há número real de clínica configurado
- o formulário não envia dados para servidor
- qualquer conversa real requer substituição da configuração de contato em produção
- os dados exibidos são apenas exemplos para portfólio

## Publicação no GitHub Pages
Este repositório contém as pastas V1 e V2. Para publicar a V2 em GitHub Pages, é necessário configurar a publicação para usar o conteúdo da pasta V2 como raiz do site, ou preparar uma branch/fluxo de deploy que publique somente esse diretório.

Não foi realizado nenhum push nem publicação automática neste momento.

## Segurança e privacidade
- não há tokens, senhas ou credenciais no código
- contatos e endereço são demonstrativos
- não há armazenamento de dados pessoais no navegador
- não há integração real com WhatsApp ativa

## Observações finais
- a página continua identificada como demonstração fictícia de portfólio
- a V1 foi preservada e não foi alterada
- qualquer publicação oficial exige revisão final de domínio, dados de contato e número de WhatsApp autorizado
